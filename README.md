## Featured Projects

### 01 — TransitIQ | Public Transport Delay Analysis

**Python · Pandas · Scikit-learn · Flask · React**

An end-to-end project exploring public transport arrival delays using weather, traffic, events and scheduling data.

- Performed exploratory data analysis and feature engineering.
- Compared regression models against a Dummy baseline.
- Investigated weak predictive relationships through permutation testing and statistical analysis.
- Developed a Flask API and React dashboard prototype.

[View Repository](https://github.com/vedanthpatil1706/public-transport-delay-prediction)

*Note: Initial experiments showed that the available dataset has limited predictive signal. Model limitations are documented rather than overstating performance.*
